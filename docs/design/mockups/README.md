# UI mockups

Concept references for **Serious Wiz Biz**. Canonical guide: [ui-aesthetic.md](../ui-aesthetic.md).  
Agent workflow: `.cursor/skills/serious-wiz-biz-ui/SKILL.md`.

## Layout

```
mockups/
  menus/           # home, pause, settings
  spellbook/       # latest locked set only
  hud/
  iconography/     # role sheets: menu, hud, item, spell-slot
```

Filename pattern (version first for sorting):

```
vN-<element>.png
```

Iconography roles (equal size/scale within each sheet):

- `vN-menu-icons.png` — Host / Join / Settings / Exit
- `vN-hud-icons.png` — status / live / cursor / mana
- `vN-item-icons.png` — inventory glyphs
- `vN-spell-slot-icons.png` — hotbar bezels + book/gem marks

Locked menu glyphs: Host = conference table, Join = owl in flight, Settings = gear, Exit = hinged door.

## Hard constraints

1. No references to trains, machines, or people. This is not a hyper realistic game, and this promises something I wont deliver.
2. The title of the game should be "Serious Wiz Biz"
3. lets move the version to the left side so that it auto sorts

(Settings gear is an allowed abstract UI glyph. Symbolic animals OK. No human figures.)
